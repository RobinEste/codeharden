PR #584 at c6f54c39: pnpm typecheck && pnpm lint && pnpm test

How it was run: Node 24.22.1, pnpm 10.12.1, macOS. PATH held a folder with only `node` and
`pnpm`, HOME was an empty folder, and the commands ran inside a macOS sandbox profile that
refuses every connection except to 127.0.0.1 and hides /usr/local and /opt/homebrew, so that no
test could start a provider CLI installed on the machine.

Result: typecheck passes, lint passes, pnpm test: 2 failed | 4501 passed | 45 skipped.
Neither failure is in code this pull request touches, and both fail the same way on untouched
upstream main (see failing-suites-on-main-91155115.txt):
- apps/runner/test/runner-link.test.ts ("aborting while the upgrade is still pending ..."): the
  known intermittent failure, also on upstream main.
- apps/runner/test/leftover-processes.test.ts ("ends the process ... and then removes the
  worktree"): caused by the sandbox, which keeps the test from seeing other processes' folders.
  Outside the sandbox the suite passes on this head (10 of 10); inside it, it fails on upstream
  main as well.
